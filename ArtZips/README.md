# ArtZips

Upload the KayKit `.zip` downloads here (on GitHub: **Add file → Upload files**).
The cloud build unpacks the glTF models (`.gltf`, `.glb`, `.bin`) and textures (`.png`) into
`art/kaykit/` and the game picks them up automatically.

GitHub's website accepts files up to 25 MB each. If a pack is bigger, tell Claude in the project chat.
